## Featured Projects

### 🔄 [Customer Churn Prediction Pipeline](https://github.com/Adnan082/LINK)
Production-grade binary classification system predicting telecom customer churn using XGBoost, Random Forest, and Logistic Regression.
- **Best Model:** Random Forest — F1: 0.911 | ROC-AUC: 0.985
- **Key Finding:** Customers with complaints churn at 83% vs 10.1% without
- **Techniques:** GridSearchCV with 5-fold stratified CV, SHAP explainability (TreeExplainer & LinearExplainer), class-imbalance handling, ROC/PR curve analysis
- **Stack:** Python · Scikit-Learn · XGBoost · SHAP · Pandas · Matplotlib

---

### ✈️ [NASA C-MAPSS Fleet Health Monitor](https://github.com/Adnan082/LINK)
Multi-agent AI system for predictive maintenance of aircraft turbofan engines using the NASA run-to-failure dataset.
- **RUL Prediction:** CNN-BiLSTM achieving MAE of 12.2 cycles
- **Anomaly Detection:** LSTM Autoencoder with per-condition adaptive thresholds
- **Decision Engine:** Rule-based classifier across 5 priority levels for 707 engines
- **Interface:** Live Streamlit dashboard with real-time KPI cards and AI chat (Claude Haiku)
- **Stack:** Python · TensorFlow/Keras · LangChain · Streamlit · asyncio

---

### 🏥 [Type II Diabetes Risk Prediction](https://github.com/Adnan082/LINK)
Supervised ML model predicting diabetes risk from clinical health data with actionable healthcare insights.
- **Accuracy:** 80%+ using optimised classification pipeline
- **Preprocessing:** Missing value imputation, normalisation, outlier treatment, correlation analysis
- **Feature Engineering:** Variable transformations and selection based on clinical relevance
- **Stack:** Python · Scikit-Learn · Pandas · Matplotlib
